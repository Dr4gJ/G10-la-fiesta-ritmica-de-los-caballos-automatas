# La Fiesta Rítmica de los Caballos Autómatas
Este proyecto fue desarrollado usando Python 3.14
```
1. Crear entorno virtual de python (desde carpeta de proyecto):
python -m venv .venv

2. Activar entorno virtual:
.\.venv\scripts\activate.bat

3. Instalar dependencias:
pip install -r requirements.txt

4. Disfrutar
py main.py
```

## Tareas repartidas
- P1: moore.py, sprites/animación del caballo (ui.dibujar_caballo)
- P2: afd.py, pista y HUD (ui.dibujar_pista / dibujar_hud)
- P3: precision.py, beats.py, ui.dibujar_beat / dibujar_feedback
- P4: juego.py, main.py, menú, cuenta regresiva, bots, pantalla de ganador
